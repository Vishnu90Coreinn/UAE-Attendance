# S4 Monthly payroll, print and PDF implementation plan

> Use superpowers:subagent-driven-development, test-driven-development and verification-before-completion. Approved scope: HANDOVER.md S4 and master plan R1–R5/R9/R10.

**Goal:** Produce identical server-calculated monthly payroll figures on screen, print and a selectable-text A4 PDF.

**Architecture:** Extend the pure calculator for monthly/grand totals. A read-only payroll service builds one report DTO from coherent SQL reads. React renders that DTO in one screen/print component. PDF generation consumes the same DTO.

**Tech stack:** Existing .NET 10 / SQL Server / React / TypeScript / Vitest. Free PdfPig 0.1.16 with embedded Noto Sans fonts replaces QuestPDF at the owner's request. The owner confirmed English prototype scope and excluded Arabic; no browser runtime is required. No schema changes.
