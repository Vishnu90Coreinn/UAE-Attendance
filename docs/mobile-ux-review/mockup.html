Supervisor mobile redesign — mockup

Seven 390×844 screens that restructure the supervisor's pages around one job: mark 12–25 workers before the shift starts, one-handed, in sun, on patchy signal. Frame 1 is interactive (tap ✓ ✕ ⋯, the filter chips, “Mark rest present”, “Save”). All names come from the seeded data; other values (leave status owners, attendance counts on the profile, the “Approved” letter action) are illustrative. Nothing here changes the app. The findings behind each choice are in critique.md.

Design rules used

One job per screenThe daily task is the home screen; reference pages stay reference.
Rows, not cardsOne record = one line of 64–76 px with state at a glance; detail on demand.
48 px minimum targets, 52 px for the repeat actionGloves, glare, one thumb. The ✓ and ✕ are 52 px.
State = colour + icon + wordNever colour alone; unmarked rows stay white so gaps are visible.
Thumb-zone actions, undo over confirmPrimary actions at the bottom; reversible toasts for cheap actions, a single prompt only where pay is affected.
Never lose workMarks are kept as a draft on the phone; saving is explicit and one pattern everywhere.
